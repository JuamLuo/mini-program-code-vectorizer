# mini-program-code-vectorizer
# 微信小程序码矢量化工具

上传微信小程序码截图，自动测绘出定位点、码点、logo 区、徽标区，
导出为纯几何的 SVG 矢量文件（每个码点都是 `<circle>` 或圆角 `<rect>`），
导入 Illustrator 后可无限放大不失真，适合印刷物料制作。

## 使用

访问 **[在线 Demo](https://你的用户名.github.io/仓库名/)** 直接使用，无需安装。

或者把 `index.html` 下载到本地，双击用浏览器打开即可（Chrome / Edge / Safari 均可）。

## 功能

- 纯前端，不上传图片到服务器，所有处理在本地完成
- 上传小程序码 → 自动识别三个定位点 → 逐连通域采样 → 生成 SVG
- 长条码点自动转成圆角矩形，不会变成一串小圆
- 中央 logo 区支持：默认从原图截取 / 上传 PNG·JPG·SVG / 清除为占位圆
- 右下角小程序徽标固定嵌入（可在代码中替换 `BADGE_SVG_RAW`）
- 所有尺寸基于两定位点距离 `sideLen` 相对计算，跨图稳定
- 调试图叠加显示算法测到的位置，方便微调

## 局限

- 针对**正放、清晰、无透视变形**的小程序码截图效果最好。拍照图片（斜拍、光照不均）需要先做透视校正，本工具暂不支持。
- 定位点比例、logo 半径、徽标位置基于一批小程序码标定，不同版本的码可能存在细微差异。如遇偏差，用界面滑块微调即可；如果系统偏差，修改代码顶部的 `BASELINE_*` 常量。
- 不支持解码内容（AppID、路径、scene 参数）——微信小程序码使用私有协议，第三方无法离线解码。本工具只做几何还原。

## 技术说明

- 图像预处理：灰度化 + Otsu 二值化
- 定位点检测：多方向扫描线 + 黑白相间模式匹配 + 聚类
- 连通域分析：4 邻域 BFS，含二阶矩和 PCA 主轴
- 码点识别：圆形连通域 → `<circle>`；长条连通域 → PCA 主轴投影 → 旋转的圆角 `<rect>`
- 所有尺寸基于 `sideLen`（三个定位点两两距离中两条直角边的平均值）相对计算
